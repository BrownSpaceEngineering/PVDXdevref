# **SCH1600 Chip Carrier PCB** 

The purpose of the SCH1600 Chip Carrier PCB is to enable fast prototyping. 

SCH1600 Chip Carrier PCB includes: 

- SCH1600 sensor soldered on PCB 

- PCB design #MFI01398 with pin headers and passive components 

Please refer to SCH1600 datasheet when using the Chip Carrier PCB.
